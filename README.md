## GitHub Pages 操作

1. 在 GitHub 创建新的独立仓库，建议名称 `wangfei-videochannels-proposal`，不要使用已有的阿里云或乡音仓库。
2. 上传本目录的 `index.html`、`.nojekyll`，提交到 `main` 分支根目录。
3. 打开仓库 **Settings → Pages → Build and deployment → Deploy from a branch**，选 `main` 和 `/(root)`，保存。
4. 待 GitHub Pages 发布完成，核对仓库 Pages 设置中显示的实际网址。通常形如 `https://<账号>.github.io/<仓库名>/`，不应在发布成功前把示例当成正式链接。
